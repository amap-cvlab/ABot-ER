# Reported results

Every published result must identify model revision, parent checkpoint(s), data release, training config, code/environment revision, evaluated step, benchmark contract, complete coverage, raw score and judge failure counts.

The root README reports Tables 8 and 10 of the technical report. These are
reported experimental results, not scores produced by repository unit tests.
The [training guide](../docs/reproduction.md) documents training stages and
checkpoint selection. New evaluation runs should retain their own configuration,
coverage and judge-failure records.
