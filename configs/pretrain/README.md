# Pretraining recipe

`q35_9b_dhta.yaml` defines the released Qwen3.5-9B Stage A recipe with the
Task-Conditioned Adaptive Training Strategy and VABench XML-eight-point data
contract. The filename retains the implementation compatibility identifier.
See the [training guide](../../docs/reproduction.md) for the original base model,
public-data verification, distributed launch and checkpoint export.
