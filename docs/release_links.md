## ModelScope datasets

ModelScope is the sole dataset distribution platform; no Hugging Face dataset
release is planned. Dataset: [ABot-ER-Training-Data](https://www.modelscope.cn/datasets/amap_cvlab/ABot-ER-Training-Data).
数据集仅通过 ModelScope 分发，不上传 Hugging Face；以上链接为训练数据入口。
For reproducible downloads, record the resolved revision and file hashes as described
in the [artifact guide](../data/artifacts/README.md); a repository URL alone is not an immutable snapshot.
Pre-training and post-training manifest information is in [Datasets](../README.md#datasets).
